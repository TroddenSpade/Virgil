# Source portrait

`virgil-bust.jpg` is a photograph of the Vatican bust of the Roman poet Virgil
(Publius Vergilius Maro).

- **Source:** Wikimedia Commons, `File:Publius Vergilius Maro.jpg`
  <https://commons.wikimedia.org/wiki/File:Publius_Vergilius_Maro.jpg>
- **Licence:** Public domain (the sculpture is ancient; the photograph is released
  as public domain).
- **Use:** the icon generator crops the head and shoulders, converts them to a
  bronze duotone and places the portrait in a Roman coin medallion. The original
  file is kept here so the icons can be regenerated.

Regenerate the icons with:

```bash
npm run icons        # python3 scripts/generate-icons.py, requires Pillow
```
